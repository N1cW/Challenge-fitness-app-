# Состояние курсового проекта

Дата: 11.10.2026 (МСК). Все созданные в текущей работе коммиты получают фактическую дату; исторические этапы 05–10 октября не выдаются за выполненные в те дни.

## Выполнено

- Изучены официальное задание Капинуса, образец Купцова и Twelve-Factor App; составлена трассировка требований.
- Реализованы веб-клиент, API, роли, база данных, участие, прогресс, таблица результатов и события WebSocket.
- Подготовлены шесть оригинальных диаграмм с редактируемыми исходниками PlantUML.
- Созданы Dockerfile и Compose, Render Blueprint для двух сервисов, одной бесплатной PostgreSQL и раздельных схем staging/prod, пример настроек и README.
- Автоматические тесты: 7 passed, 1 warning. Локальные HTTP и WebSocket проверки пройдены.
- Подготовлены и визуально проверены курсовая работа и девятислайдовая презентация; снимок главной страницы предоставлен пользователем.
- Созданы исходный архив и архив диаграмм; исходники опубликованы в `origin/main` с проверкой совпадения локального и удалённого HEAD.

## Ограничения

- Docker Engine недоступен, поэтому запуск связки Nginx — API — PostgreSQL в контейнерах не проверен. Синтаксис Compose проверен.
- Первая синхронизация Render создала production-БД и остановилась из-за лимита на вторую бесплатную БД. Blueprint исправлен для одной БД; веб-сервисы требуют повторной ручной синхронизации.
- `gh` отсутствует в PATH данной сессии; публикация выполнена прямым `git push` с проверкой удалённой ветки.

## Для полной проверки развёртывания

После запуска Docker Engine проверить связку Nginx — API — PostgreSQL. В Render выполнить Manual sync и проверить оба веб-сервиса.
