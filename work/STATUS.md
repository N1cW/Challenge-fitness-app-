# Состояние курсового проекта

Дата: 11.10.2026 (МСК). Все созданные в текущей работе коммиты получают фактическую дату; исторические этапы 05–10 октября не выдаются за выполненные в те дни.

## Выполнено

- Изучены официальное задание Капинуса, образец Купцова и Twelve-Factor App; составлена трассировка требований.
- Реализованы веб-клиент, API, роли, база данных, участие, прогресс, таблица результатов и события WebSocket.
- Подготовлены шесть оригинальных диаграмм с редактируемыми исходниками PlantUML.
- Созданы Dockerfile и Compose, пример настроек и README.
- Автоматические тесты: 6 passed, 1 warning. Локальные HTTP и WebSocket проверки пройдены.
- Подготовлены и визуально проверены пояснительная записка и девятислайдовая презентация; снимок главной страницы предоставлен пользователем.

## Ограничения

- Docker Engine недоступен, поэтому запуск связки Nginx — API — PostgreSQL в контейнерах не проверен. Синтаксис Compose проверен.
- Платформа и доступ для облачного развёртывания не предоставлены. Облачная публикация не выполнена.
- `gh` отсутствует в PATH данной сессии; фактическая возможность публикации Git проверяется прямым `git push` после ревизии файлов и авторства.
